Bibliothèque de choix

Change le type de palette par produit. Les Handi-Pac sont sur CHEP par défaut; les autres isolants restent sur palettes panneaux 4×8.

Scénario automatique

Crée un scénario avec une palette de chaque produit, en respectant le type de palette défini dans la bibliothèque. Les familles sont regroupées dans les mêmes sections autant que possible.

Outil d’optimisation

Entre les palettes à placer. L’outil regroupe les familles puis remplit les baies de gauche à droite.
